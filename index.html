帮助与反馈

零、运行模式与基本操作

  • 顶栏右侧 地铁模式 / 国铁模式 切换；切换后页面自动重载并记住上次模式，两种模式的线网各自独立保存、互不覆盖。
  • 顶栏 筛选（地理图专用）：下拉选择某条线路 → 地理图上该线保持高亮发光、其余线路 / 站点 / 列车变暗约 72%（保留原色相，不是变灰）；默认「全部线路」即不筛选。与左侧行车调度面板的操作线路是独立的两个选择器，互不干扰。
  • 顶栏 1x / 2x / 4x / 8x 调节仿真倍速；「全线暂停」「运营复位」随时可控。列车位移按各自制式的速度（km/h）等比换算，快车与慢车的相对快慢比例始终不变。
  • 双时间体系：顶部时钟显示本机真实时间（年-月-日 时:分:秒.毫秒），始终不变；所有行车、调度、时刻表、运行图均使用独立的内部运营时间（从 05:00 起算，可见于「运行概况」面板的「运营时间」）。倍速与暂停仅作用于内部运营时间，不影响顶部真实时钟。
  • 顶栏页签：地理图 / ATS拓扑 / 调度室 / 运行图；右侧「帮助」打开本指南。

一、日常调度（左侧面板）

  • 运行概况：运营时间（内部虚拟时间）、在线列车、累计客运量、扣车 / 故障、封闭车站总数。
  • 首末班车（地铁制式）：每条地铁线路默认首班 05:30、末班 23:00，可在编辑模式下逐线修改。到达首班车时刻自动投放上、下行列车；末班车时刻后，列车到达终点站（环线为到达首站）即回库退出运营，不再折返。国铁制式无首末班机制，全天按图运行。
  • 行车调度：选择线路 → 加开列车 / 末班回库 / 暂停本线；车次行内可下发 扣车 / 跳停 / 故障 / ATS 指令（紧急停车、区间封锁、降级限速）。
  • 车站管控：点击车站名封闭 / 解封；地理图、ATS 拓扑图、布置图上也可直接点击车站。
  • 自然灾害预警：灾害类型 + 预警等级 + 影响范围（全线网 / 线路 / 区段 / 车站）发布，联动 ATS 限速、封锁并自动扣停受影响列车；红Ⅰ解除后进入限速验证，需调度确认。视觉反馈四级递进——蓝Ⅳ / 黄Ⅲ 横幅分级着色 + 画布边缘渐晕；橙Ⅱ 横幅闪烁 + 橙色渐晕呼吸脉冲；红Ⅰ 横幅强闪 + 红色渐晕急促脉冲；面板状态行带等级色呼吸圆点与色条。

二、四大视图

  • 地理图：按真实地理位置绘制线网；滚轮缩放、按住拖动平移；左下「线路一览」可收起；列车 ● 黄边=快车、紫标=小交路。顶部筛选下拉可单独高亮某条线路，其余线路 / 站点 / 列车变暗便于专注观察；换乘站同名同坐标只绘制一次。
  • ATS 拓扑图：查看信号机、光带与车次窗；点击车次窗 → 详细信息与指令；点击区间轨道 → 封锁 / 降级；点击车站 → 封闭 / 解封。
  • 调度室：设备布置图（第三节）与专业版 CTC 站场图（第四节）。
  • 运行图（时距图）：X 轴为固定 24 小时时间轴（00:00 ~ 24:00），Y 轴为车站；橙色虚线为当前运营时刻。每列车绘制计划线（虚线·浅色）与实际线（实线·亮色），直观对比到发偏差；下方状态栏显示准点率（偏差 ≤ 60s 为准点）。底部时刻表按车次列出各站计划 / 实际到达时刻，准点绿、晚点红、早点蓝。

三、调度室 · 设备布置图

  • 按线网里程比例绘制全线：正线 / 到发线 / 道岔（左端奇数、右端偶数）/ 渡线 / 联络线 / 站台 / 车站规模（国铁按「几台几线」标注）。
  • 道岔可点击：点击图中道岔 ● 弹出信息小窗（编号 / 类型 / 位置 / 连接关系），按住标题栏可拖动，点画布空白或 ✕ 关闭。
  • 右侧面板：设置车站台数 / 股道数 / 站台型式、正线双线或单线，增删 渡线（支持交叉渡线与正向 / 反向）与 联络线（支持交叉联络线与自下行 / 自上行引出），即改即存。
  • 站台（地铁模式）：站场纵向拉伸，站台矩形上 / 下缘紧贴两侧股道的门带；站台型式支持 岛式 / 侧式 / 一岛一侧。每个站台边缘各一条站台门带，按对应股道独立驱动：灰=关闭、琥珀=停稳待开、绿=开启、黄闪游走=进站待机。
  • 开关门时序：列车到站停稳 1.2s 后才开门（1.1s 滑开）→ 开门停留 → 距发车 1.7s 关门（1.1s 滑闭）→ 门完全关闭后再确认 1s 才发车。停站总时长 18s（约 13.6s 为开门停留）。
  • 发车倒计时：固定在运行方向的站台外侧（上行→右端、下行→左端），并按停靠股道对齐；显示「3道 发车 12s」/「Ⅰ道 扣停」/「Ⅱ道 紧停」，空闲时显示「待发」。
  • 停靠股道分配：上行只使用 Ⅰ道 与上半区股道，下行只使用 Ⅱ道 与下半区股道——即只选经本站咽喉与该方向正线连通的股道；同类股道间按 车次 + 站序 轮换并避开占用。列车进站前约 3 秒巡航里程即预排股道，进 / 出站经过咽喉时在「正线行 ↔ 股道行」间平滑过渡，不会瞬移切道。
  • 换乘标注（地铁）：同站名即换乘；两线同为岛式且股道数一致标 同台换乘，否则标 通道换乘。
  • ATS 实时叠加：勾选后叠加 列车车次箭头、占用红光带、封锁紫、降级青、封闭车站红✕；「列车情况」面板列出 车次 / 位置（含股道）/ 速度 / 状态。站台门与发车倒计时为常驻动画，不受该开关影响。

四、调度室 · 专业版 CTC 站场图

  • 工具条点「专业版 CTC」进入：全线各站站场横向连续排列，可滚动、下拉或点击站名卡定位。
  • 站场构成：上下行正线（Ⅰ / Ⅱ）+ 到发线（3 号起，按车站规模自动生成）+ 两端咽喉道岔群 + 咽喉渡线 / 联络线引出。
  • 道岔交互：点击岔尖弹出小窗（站名 / 道岔编号；状态：定位白 / 反位黄 / 单锁绿圈 / 封锁红叉 / 进路锁闭白圈），可执行 单操定位 / 单操反位 / 单锁 / 解锁 / 封锁 / 取消封锁；操作后窗口保留并实时刷新。左咽喉奇数、右咽喉偶数编号。进路锁闭中的道岔禁止单操、单锁与封锁，需先关闭相应信号。
  • 信号机 · 进路联锁：每条股道两端设信号机，按现场规则命名（S=上行接车 / X=下行接车 + 道号，如 S3、XⅡ）。点击信号机 = 排列接车进路：依次执行联锁检查——方向合理性（上行不可接入Ⅱ道）、对向敌对进路、股道占用、沿途道岔封锁 / 单锁冲突；全部通过后自动转辙道岔至反位并进路锁闭（白圈标记），进路光带自信号机沿咽喉分支至股道全程点亮。再次点击 = 关闭信号、取消进路并解锁道岔；列车进入股道后信号自动关闭、进路自动解锁（仿 CTC 信号复示）。联锁检查不通过时调度日志给出具体原因。
  • 轨道电路占用红光带：站停 / 扣停列车所在股道、区间列车自区间入口至当前位置的已占用区段实时亮红，与 ATS 占用显示一致。
  • 悬浮状态查询：鼠标悬停 列车带（车次 / 位置 / 速度 / 状态 / 正晚点）、信号机（名称 / 进路 / 开放状态）、道岔（编号 / 位置 / 锁闭状态）、站名卡（车站规模）即显示实时状态。
  • 列车带：在线列车以彩色车次带显示在股道或正线上（停站时标注股道号），进 / 出站同样沿咽喉平滑过渡；点击车次带即追踪。
  • 底部信息条显示 时钟 / 即开车次 / 站场统计（含信号开放与进路数）。与布置图数据互通：车站规模、渡线、联络线改动即时互相生效。

五、编辑模式与数据管理

  • 点顶部「进入编辑模式」：单击空白处追加车站、点在线路段上插入车站、拖拽车站移动位置；车站列表点「换」→ 再点另一线车站 = 设为换乘站（同名自动合并坐标）。
  • 选中线路后可改名、换色、设环线、切换制式 / 车型 / 编组 / 站台 / 站台门 / 预留方案；地铁制式还可设置首班车 / 末班车时间（默认 05:30 / 23:00，国铁制式无此选项）；「线网编辑」面板顶部可手动设置画布长宽。
  • 数据管理：导出 / 导入线网配置（JSON，含首末班车）、导出运行数据、恢复默认线网；面板标题可折叠，折叠状态与画布尺寸自动记忆。

六、国铁模式：发车规则与加开列车

  • 国铁模式不自动发车：进入系统后全线无车，所有列车由调度员手动加开，真实还原 CTC 计划开车流程；地铁模式仍按计划自动发车。
  • 加开流程：「行车调度 → 加开列车」→ 在 国铁加开选项 中选择 制式大类（复兴号 / 和谐号 / 普速列车 / 货运班列 / 货运动车组）→ 子型号（两级级联，决定车次字头 / 旅行速度 / 站停时间）→ 填写 自定义车次（留空自动）→ 勾选 重联运行 → 选择 全程车 / 小交路、始发方向、大站快车及停靠站 → 「确认加开」。
  • 停站与股道：逐站设置「停（自动分配股道）/ 不停（正线通过）/ 具体股道停靠」。选项按当前始发方向只列出可连通股道（例如上行车不会出现 4道 / Ⅱ道），切换方向、切换大站快车或修改停靠勾选时列表即时刷新，已选股道在新方向下不可达时自动回退为「自动分配」；大站快车未勾选的站默认「不停」。选「不停」的车站列车经正线直接跨站。
  • 制式选择仅在「加开列车」表单展开时显示，平时收起；所选制式仅随本次加开的列车生效，不影响线上既有列车与本线默认制式。

七、国铁模式：制式、车型与车站属性

  • 国铁制式分 复兴号 / 和谐号 / 普速列车 / 货运班列 / 货运动车组 五大类，采用「大类 → 子型号」两级选择：复兴号内置 27 种子型号（CR450AF 新一代、CR400 系列 标准 / 高寒 / 智能 / 技术下放款、CR300 系列等），和谐号内置 36 种子型号（CRH1 / CRH2 / CRH5 / CRH6 / CRH380 系等），每种子型号独立适配最高运行速度与旅行速度；普速与货运按车底（25T / 25K / 25G 等）与班列类型选择。国铁模式下不显示地铁 / 轻轨等非国铁制式。
  • 布置图右侧面板的制式是本线默认制式（决定自动生成车次的字头基准）；加开表单中的制式仅随车生效，车次方案重排时每列车仍按自己的子型号取字头，普速车不会被误排为 G。
  • 「国铁调度台（CTC）→ 车站属性」中可设置每站的 车站长度（m） 与 是否有屏蔽门，选择车站后即改即存。

八、国铁模式：车次头方案与字头对照

  • 「国铁调度台（CTC）→ 车次方案」可切换 新式 / 老式 两种字头规则；切换后立即按新方案重排全部在线车次，新旧字头不会混跑。
  • 新式（2026版《列车车次编排规定》）：高速旅客列车 X 新（新一代复兴号，最高运行时速 350km/h 以上）· G 高（复兴号，350km/h）· T 特（动车组，300km/h）· K 快（动车组，200~250km/h）；动集旅客列车 D 动（动力集中，200km/h 及以下）；城际旅客列车 C 城（200km/h 及以下）；市域(郊)旅客列车 S 市郊（160km/h 及以下）；普速旅客列车 Z 直（160km/h）· N 慢（140km/h）· V 慢（120km/h，25G 等普速车底）；普速旅游列车 Y 游；货物列车 B 班（货运班列，90~160km/h）· DH 动货（动力组快运）。
  • 老式（至 2026 年 1 月前）：高速动车组 G（CRH380 系 / CRH3 型 / CRH2C / CR400 / CR450）· 动车组 D（CRH1 / CRH2A / CRH5 系等 200~250km/h 及动集）· 城际 C（CRH6A）· 市域 S（CRH6F）· 普速 K · 货运班列 B · 货运动车组 DH。
  • 车次号按「字头 + 线路号 / 班次」自动编号，上行取双号、下行取单号；数字号段按 2026 版号段资源编排（C/S≤2998、Z/N≤1998、V 6001~6998、X/G/T/K/D≤9998），超界自动回绕以保证车次唯一。

九、国铁模式：CTC 调度台（区间管控与正晚点）

  • 区间管控：在「国铁调度台（CTC）→ 区间管控」中对每个站间区间设置 正常 / 慢行（限速）/ 封锁；也可直接在 ATS 拓扑图上点击区间轨道切换。
  • 正晚点：列车因限速、封锁、扣车产生的晚点会实时累积，恢复正常后逐步回落，在「车次运行监督」中按正 / 晚点显示。
  • 「车次运行监督」实时列出在线车次的 车次 / 字头 / 线路车型 / 位置（含股道）/ 状态 / 正晚点，支持对单列车直接下发 扣停 / 放行、故障 / 修复、追踪等指令。

十、列车运行与站台作业时序（速查）

  • 速度换算：列车速度按 km/h 语义参与限速、预警与显示，画布位移统一按等比系数换算，因此快车始终比慢车快，且不会出现「一站 1 秒」。
  • 停站 18s = 停稳确认 1.2s + 开门 1.1s + 开门停留 13.6s + 关门 1.1s + 关闭确认 1s；扣车时门保持关闭且不计时，放行后补停 6s 走完整轮开关门。
  • 股道占用：列车停站或已预排某站股道时，同站同股道不会再被分配给另一列车；预排距离约为 3 秒巡航里程（30~150px 画布距离）。

系统定位

一个完整的地铁 / 国铁调度仿真与演练工具。涵盖线网编辑、列车运行仿真、ATS 列车追踪、信号 / 闭塞 / 进路联锁、站场布置图、专业版 CTC 站场图、自然灾害预警联动与调度指令演练。两种模式各自独立保存、互不覆盖。

核心特性

  • 双模式独立运行：地铁模式（自动按图发车）/ 国铁模式（手动 CTC 计划开车），localStorage 分库记忆
  • 四大视图联动：地理图 / ATS 拓扑 / 调度室（布置图 + CTC 站场）/ 运行图，数据互通、上下文联动
  • 真实调度要素：信号机命名（S3 / XⅡ）、进路联锁检查（方向合理 / 敌对 / 股道占用 / 道岔封锁）、进路锁闭与自动解锁
  • 站台门与股道：岛式 / 侧式 / 一岛一侧站台，差异化开关门时序，发车倒计时，停靠股道方向分区与咽喉平滑过渡
  • 首末班车机制（地铁）：逐线可配，末班后列车到终点自动回库
  • 自然灾害预警：蓝Ⅳ / 黄Ⅲ / 橙Ⅱ / 红Ⅰ 四级，联动 ATS 限速、封锁、扣停，红Ⅰ 解除后限速验证期需调度确认
